## Monday Morning Punchlines

One joke about Monday mornings, 200 characters at most, judged on laughs. A judge model reads the jokes two at a time and picks the funnier one, weighing whether the joke is really about Monday mornings, whether the punchline lands, surprise, economy of words and freshness.

This entry is one line in the first person: five alarms set for Monday morning form a union, go on strike, and now the snooze button is their lawyer. The joke turns a familiar Monday ritual sideways instead of just complaining about Mondays.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`): one line of plain text, at most 200 characters.
